> 공식 Kubernetes 1.34 릴리스 정보를 근거로 작성된 문서입니다. 현재 검증 대상
> patch는 v1.34.10입니다. 출처는 문서 하단 참고.

## 개요

- 코드명 "Of Wind & Will (O' WaW)", GA 2025-08-27.
- 58개 Enhancement(23 Stable, 22 Beta, 13 Alpha). 이 릴리스 자체는 API 제거나
  치명적 Deprecation이 없어 이전 릴리스들보다 업그레이드 충격이 작은 편입니다.

## Deprecated API / 설정

- kubelet 설정 파일의 `cgroupDriver` 필드 및 `--cgroup-driver` 커맨드라인
  옵션이 Deprecated 처리되었습니다. 1.34~1.35 동안은 유지되지만 **1.36에서
  제거될 예정**이므로, 업그레이드 전 자동 cgroup driver 감지로 전환해야 합니다.
- containerd 1.7.x 계열이 이 버전에서 Deprecated 처리되었습니다. containerd
  1.7 LTS 브랜치의 프로젝트 자체 지원 종료(EOS)는 2026-09-01이며, 별도로
  kubelet이 구버전 CRI 런타임(`RuntimeConfig` RPC 미지원 런타임, containerd
  1.x 포함)에 대해 `--cgroup-driver` 값으로 fallback하는 경로는 공식
  Container Runtimes 문서 기준 **1.38에서 제거 예정**입니다(이전에는 1.36으로
  기재돼 있었으나 `compatibility-matrix/containerd.md` 재검증 결과 정정).
  1.32~1.36 구간에서는 여전히 정상 동작하지만, containerd 2.0 이상으로의
  전환 계획은 미리 세워야 합니다.
- Service의 `PreferClose` Traffic Distribution 정책이 Deprecated 처리되었고
  1.36부터는 alias로만 동작합니다. `PreferSameZone` / `PreferSameNode` 사용을
  권장합니다.

## etcd 변경

- kubeadm 기본 지원 etcd 버전이 3.5.21-0 → **3.6.5-0**으로 상향되었습니다.
  etcd 3.6.0 이상으로 직접 업그레이드하기 전에 먼저 3.5.20 이상 patch로
  올려야 합니다(공식 kubeadm 가이드 권고).
