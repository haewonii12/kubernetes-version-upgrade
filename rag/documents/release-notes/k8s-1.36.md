> 공식 Kubernetes 1.36 릴리스 정보를 근거로 작성된 문서입니다. 현재 검증 대상
> patch는 v1.36.3입니다. 출처는 문서 하단 참고.

## 개요

- 코드명 "ハル (Haru)", GA 2026-04-22.
- 70개 Enhancement(18 Stable, 25 Beta, 25 Alpha). User Namespaces(Pod),
  Fine-Grained Kubelet API Authorization, Declarative Validation, PSI
  Metrics, Volume Group Snapshots, SELinux Volume Label 변경,
  MutatingAdmissionPolicy 등이 GA로 승격되었습니다.

## Urgent Upgrade Notes

- **Metric 이름 변경**: `volume_operation_total_errors` →
  `volume_operation_errors_total`, `etcd_bookmark_counts` →
  `etcd_bookmark_total`. 관련 Dashboard/Alert 룰 업데이트가 필요합니다.
- **kubeadm flex-volume 통합 제거**: kubeadm이 더 이상 flex-volume을 자동
  통합하지 않습니다. 계속 사용하려면 `--flex-volume-plugin-dir`가 설정된
  커스텀 KCM 이미지를 직접 준비하고 디렉터리를 수동 마운트해야 합니다.
- Scheduler PreBind plugin이 `AllowParallel: true`를 반환하면 병렬 실행을
  opt-in할 수 있습니다(기본은 기존과 동일한 순차 실행 유지).

## Deprecated API

- Service `.spec.externalIPs` 필드가 보안 우려로 Deprecated 처리되었습니다
  (완전 제거는 v1.43 예정). LoadBalancer Service, NodePort, 또는 Gateway
  API로의 전환을 권장합니다.
- Credential plugin의 `AllowlistEntry.Name`이 `AllowlistEntry.Command`로
  변경(rename)되었습니다.
- `FieldsV1` 직접 필드 접근이 Deprecated 처리되었습니다 —
  `NewFieldsV1(string)` / `GetRawBytes()` 접근자 사용을 권장합니다.

## Removed / 기본값 변경

- `git-repo` volume plugin이 **기본적으로 비활성화**되었고 다시 켤 수 있는
  옵션이 없습니다(1.33에서 제거된 `gitRepo` volume type과는 별개로, plugin
  자체가 막혔습니다).
- kubelet의 cgroup driver 자동 감지가 정착되어, 수동 `cgroupDriver`
  설정(1.34부터 Deprecated)이 이 버전부터 제거되었습니다.

## cgroup v1 지원 (참고 — `k8s-1.35.md` 문서와 함께 확인)

- 이 릴리스에서 `FailCgroupV1` 기본값은 1.35와 동일하게 `true`이며, 1.36에서
  추가로 변경된 사항은 확인하지 못했습니다.
- 일부 서드파티 자료는 "1.36에서 cgroup v1 완전 제거"라고 서술하지만, 공식
  KEP-5573 마일스톤은 실제 코드 제거를 1.38 이전으로 못박지 않았습니다.
  상충되는 정보이므로 **Manual Verification 권장** — 본 문서는 자동 판정에
  "cgroup v1 완전 제거"를 근거로 사용하지 않습니다.

## DRA (Dynamic Resource Allocation) 권한 변경

- `DRAResourceClaimGranularStatusAuthorization` feature gate 활성화 시,
  scheduler/controller는 `resourceclaims/binding`에 대한 `update`/`patch`
  권한이, DRA driver는 `associated-node:update` 또는 `arbitrary-node:update`
  권한이 RBAC으로 별도 부여되어야 합니다.

## etcd 변경

- kubeadm 기본 지원 etcd 버전: 3.6.5-0 (1.34부터 동일).
