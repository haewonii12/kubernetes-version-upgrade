> 공식 Kubernetes 1.32 릴리스 정보를 근거로 작성된 문서입니다. 현재 클러스터가
> 실행 중인 patch는 v1.32.13이며, 아래 내용은 1.32 minor 전체에 적용되는
> 변경사항입니다(patch 릴리스는 대부분 버그 수정). 출처는 문서 하단 참고.

## 개요

- 코드명 "Penelope", GA 2024-12-11.

## Removed API

- `flowcontrol.apiserver.k8s.io/v1beta3` (FlowSchema, PriorityLevelConfiguration)가
  이 버전에서 **제거**되었습니다. 대체 API는 `flowcontrol.apiserver.k8s.io/v1`
  (1.29부터 사용 가능)입니다.
- `spec.limited.nominalConcurrencyShares`를 명시적으로 0으로 설정한 경우 더 이상
  자동으로 30으로 대체되지 않습니다(이전 버전과 동작이 다름에 유의).

## Feature Gate / API 변경

- `DRAControlPlaneController` feature gate(1.26부터 Alpha)가 제거되었습니다.
- Dynamic Resource Allocation(DRA)의 아키텍처가 이 버전에서 크게 변경되었습니다.
- ServiceAccount에 붙던 `kubernetes.io/enforce-mountable-secrets` 어노테이션이
  제거되었습니다. Secret 접근 격리는 별도 Namespace 분리로 대체하십시오.

## etcd 변경

- kubeadm이 관리하는 기본 지원 etcd 버전: 3.5.21-0.
