> 공식 Kubernetes 1.33 릴리스 정보를 근거로 작성된 문서입니다. 현재 검증 대상
> patch는 v1.33.13입니다. 출처는 문서 하단 참고.

## 개요

- 코드명 "Octarine", GA 2025-04-23.

## Deprecated API

- v1 Endpoints API가 EndpointSlice API를 선호하는 방향으로 Deprecated
  처리되었습니다(계속 지원되며 제거 계획은 없음). 신규 워크로드는 EndpointSlice
  사용을 권장합니다.
- Pod `status.resize` 필드가 Deprecated 처리되었고 더 이상 채워지지 않습니다.
  대신 `PodResizeInProgress` / `PodResizePending` Condition을 확인해야 합니다.

## Removed API / 기능

- `gitRepo` volume type이 제거되었습니다(1.11부터 Deprecated 상태였음). Init
  Container + git clone 방식으로 전환하십시오.
- Windows Pod에서 `hostNetwork: true` 사용이 철회(제거)되었습니다.
- `status.nodeInfo.kubeProxyVersion` 필드가 제거되었습니다.

## etcd 변경

- kubeadm 기본 지원 etcd 버전: 3.5.21-0 (1.32와 동일).
